# HabitPulse 🎯

**🌐 [Visit HabitPulse Landing Page](https://www.habit-pulse.com/)**

A gamified habit tracking application that transforms your daily routines into an engaging experience. Build better habits with game-like motivation, level progression, and achievement systems.

## ✨ Features

### 🎮 Gamification Elements
- **Experience Points (XP)** - Earn XP for completing habits
- **Level Progression** - Advance through levels as you build consistency
- **Achievement System** - Unlock achievements for milestones
- **User Profile** - Track your progress and view your stats

### 📱 Core Functionality
- **Habit Management** - Create, edit, and delete custom habits
- **Daily Tracking** - Mark habits as complete with instant feedback
- **Calendar View** - Visualize your habit completion history
- **Statistics Dashboard** - Analyze your progress with detailed stats
- **Responsive Design** - Works seamlessly on desktop and mobile

### 🎨 User Experience
- **Modern UI** - Clean, intuitive interface built with DaisyUI
- **Side Navigation** - Easy navigation between different sections
- **Real-time Updates** - Instant UI feedback without page refreshes
- **Mobile-First** - Responsive design with hamburger menu on mobile

## 🛠️ Tech Stack

### Frontend
- **Next.js 15** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **DaisyUI** - Component library for consistent styling
- **Zustand** - Lightweight state management

### Backend & Services
- **Supabase** - Backend-as-a-Service for authentication and Postgres database
- **Google OAuth** - Secure authentication
- **PostHog** - Analytics and user insights

### Development Tools
- **ESLint** - Code linting and formatting
- **Iconify** - Icon system with extensive library
- **Date-fns** - Date manipulation utilities
